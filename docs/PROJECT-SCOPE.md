# Project Scope — Baseline v1

Status: **LOCKED**  
Approved: **2026-09-16**

## Product

Nail Karataş Interactive Sales Gallery is an interactive real-estate presentation and sales experience.

It is inspired by interaction patterns observed in Fortes Vision, but it is not a clone and must use the Nail Karataş project's own information architecture and visual design.

## Initial demo must prove the complete interaction chain

Home / Masterplan  
→ hover and select Block A, B, or C  
→ pre-rendered camera transition  
→ block view  
→ hover and select an independent unit  
→ Unit Quick Card  
→ working Virtual Tour  
→ navigate between panorama scenes  
→ return to the unit / block  
→ return Home using the reverse camera transition.

## Initial demo includes

- General project view.
- A / B / C block hover highlight.
- Synchronized block buttons and scene highlight.
- Real transition videos for all three blocks.
- Reverse Home transitions.
- Block views.
- SVG unit hotspots.
- Unit hover highlight.
- Unit Quick Card.
- Small floor-plan preview where data exists.
- Virtual Tour button.
- Working 360 panorama experience.
- Panorama hotspots.
- Room / scene menu.
- Tour minimap / plan overlay.
- Active panorama viewpoint indicator.
- Return-to-unit navigation.
- Project promotional animation accessible from global navigation.

## Initial demo does not include

- Availability page UI.
- Favorites.
- Lead-gated floor-plan download.
- CRM.
- Backend / admin panel.
- Full brochure workflow.
- Production contact workflow.
- Full production unit-detail page.

## Required future readiness

The architecture must allow future addition of:

- Availability filtering and listing.
- Full Unit Detail pages.
- Amenities galleries.
- Brochure.
- Location.
- Contact.
- Sales-status integration.
- Analytics.
- Backend / API data source.

Future readiness does not authorize implementing those features now.
