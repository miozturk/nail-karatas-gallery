# Reference Behavior Notes — Fortes Vision

This document records observed interaction ideas only. It is not a specification to clone the reference.

Observed useful patterns:

- Masterplan scene with building hover highlight.
- Scene highlight synchronized with a corresponding navigation button.
- Block selection opens an apartment / unit selection mode.
- Unit selection opens a quick information card.
- Quick card contains a small plan and Virtual Tour action.
- Virtual Tour supports panorama hotspots.
- First tour use may show interaction instructions.
- Tour can show a floor-plan minimap with camera / viewpoint markers.
- Active viewpoint is visually distinct.
- Minimap can be collapsed.
- Room / viewpoint navigation can also be exposed through a menu.
- Amenities menu can synchronize hover with highlighted regions in the main scene.
- Amenity details may use ordinary static image galleries.
- Global navigation may expose Masterplan, Availability, Tours, Video, Brochure, Location and Contact.
- Availability can list/filter units and link to deeper unit detail.
- Favorites exists in the reference but is explicitly out of scope for this project.

Nail Karataş decisions always take precedence over this reference.
